Tic Tac Toe Game 
A simple and interactive Tic Tac Toe Game built using modern web technologies. This project allows two players to play the classic Tic Tac Toe game with a clean user interface, smooth gameplay, and responsive design.

Features 
1.Two-player game mode
2.Interactive and user-friendly interface
3.Real-time win/draw detection
4.Restart game functionality
5.Responsive design for mobile and desktop
6.Clean and organized code structure

Technologies Used 
HTML
CSS
JavaScript

Project Objective 
The main objective of this project is to practice front-end development concepts such as DOM manipulation, event handling, game logic implementation, and responsive UI design.
